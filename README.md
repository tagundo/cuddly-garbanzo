# SIFAS YouTube 제목·설명 생성기

스쿠스타(SIFAS) MOD/MV 영상의 **일본어·한국어·영어 제목, 재생목록, 해시태그**를 만드는 도구입니다.

**실행에 필요한 파일은 `index.html` 하나입니다.** 화면, 생성 로직, 기본 데이터가 모두 들어 있습니다. Python, 별도 JSON, 패키지 설치, 빌드, 로컬 서버가 필요하지 않습니다. README는 사용 설명서이며 실행에 필요하지 않습니다.

## 바로 사용하기

### 맥북

1. `index.html`을 다운로드합니다. GitHub 파일 화면의 **Download raw file** 버튼을 이용하세요.
2. Finder에서 파일을 **Safari 또는 Chrome으로 열기**합니다.
3. 곡·아티스트·의상·MOD를 선택한 뒤 언어별 **복사** 또는 **전체 설명 복사**를 누릅니다.

로컬 HTML의 생성 기능은 인터넷 연결 없이 동작합니다. 외부 폰트·라이브러리·API 요청은 없습니다.

### 안드로이드

- **웹 주소로 사용:** 이 저장소를 GitHub Pages로 제공하면 Chrome 또는 Samsung Internet에서 주소를 열어 사용할 수 있습니다. 아래 설정 방법을 참고하세요.
- **파일로 사용:** `index.html` 또는 앱에서 저장한 HTML을 휴대폰으로 옮겨 JavaScript를 실행할 수 있는 브라우저로 엽니다. Android 버전·파일 앱·브라우저에 따라 로컬 HTML을 여는 방식이 다릅니다. 파일 앱의 단순 미리보기나 JavaScript가 제한된 HTML 뷰어에서는 작동하지 않을 수 있습니다. 이 경우 웹 주소로 접속하세요.
- 좁은 화면에서는 하단 **영상 선택 / 제목·설명** 탭으로 전환합니다. 캐릭터별 의상, 필터, 템플릿 등은 접어서 표시합니다.

### GitHub Pages로 URL 만들기

아래는 저장소 소유자가 최초 한 번 하는 선택 설정입니다. HTML 파일을 올리는 것만으로 Pages가 자동 활성화되지는 않습니다.

1. 원하는 버전의 `index.html`이 `main` 브랜치 최상위에 있는지 확인합니다. 변경 사항이 PR에 있다면 먼저 해당 버전을 병합합니다.
2. 저장소 **Settings → Pages → Build and deployment**에서 **Deploy from a branch**를 선택합니다.
3. **main / (root)**를 선택하고 저장합니다.
4. GitHub가 게시 완료 후 보여 주는 주소로 접속합니다. 이 저장소의 기본 Pages 주소 형식은 `https://tagundo.github.io/cuddly-garbanzo/`입니다.

Pages 활성화·게시 완료 여부는 GitHub 설정 화면에서 확인해야 합니다. 웹 주소의 최초/재접속에는 인터넷이 필요합니다. 이 앱은 서비스 워커를 설치하지 않으며, 홈 화면 바로가기가 오프라인 설치를 보장하지 않습니다.

## 맥북 ↔ 안드로이드로 작업 옮기기

상단의 **HTML로 저장**을 누르세요. **현재 곡·의상·번역·설정 데이터와 선택 상태가 모두 들어 있는 새 HTML 파일**을 내려받습니다.

그 파일 하나를 다른 기기로 보내 열면 이어서 사용할 수 있습니다. 별도 JSON을 함께 보낼 필요가 없습니다. 저장한 HTML에는 독립된 저장 구분값이 있어 같은 브라우저의 기존 작업이 파일에 내장된 상태를 덮어쓰지 않습니다.

브라우저의 자동 저장은 원본 HTML 파일을 직접 수정하지 않습니다. 다른 기기에 최신 내용을 보낼 때는 **HTML로 저장**을 다시 눌러 새 파일을 받으세요. 기기 간 자동 동기화 기능은 없습니다.

## 주요 기능

| 기능 | 사용 방법 |
| --- | --- |
| 다국어 제목·전체 설명 | 선택할 때마다 자동 생성. 언어별 제목과 전체 설명을 따로 복사 |
| 곡·의상 검색 | 고유 이름, 한국어, 일본어, 영어 표시명으로 검색 |
| 그룹·다중 솔로 | 캐릭터 유형을 선택하고 함께 표시할 캐릭터를 목록에 추가 |
| 데이터 편집 | 아티스트·곡·의상 옆의 추가/편집/삭제 버튼 사용. 기존 추가 필드는 보존 |
| 캐릭터별 의상 | 캐릭터마다 카테고리를 관리하고 등록된 의상을 현재 영상에 적용 |
| MOD와 값 | 여러 MOD를 선택. 값 사용을 켠 MOD는 영상별 값을 바로 입력 |
| 화면비 | 기본 16:9, 16:10, 4:3, 21:9, 9:16, 1:1. 목록 편집과 표시 안 함 지원 |
| 템플릿 | 일본어·한국어·영어 포맷과 설명에 포함할 언어, 줄 순서를 편집 |
| 글자 수 안내 | 제목 100자·전체 설명 5,000자 초과 시 안내. 임의로 잘라내지 않음 |
| 복사 대안 | 자동 복사가 제한되면 직접 선택할 수 있는 창 제공. 설명 TXT 저장 지원 |
| 공유 | Web Share API를 사용할 수 있는 브라우저에서 공유 버튼 표시 |

기존 기본 데이터 **100곡 / 13그룹 / 30캐릭터 / 88의상 / 5 MOD**와 재생목록 정보를 포함합니다. 존재하지 않는 곡을 카테고리가 참조할 경우 선택 목록에서 제외하고, 중복된 참조는 한 번만 표시합니다. 누락된 곡이나 번역을 임의로 만들어 넣지는 않습니다.

### 템플릿 변수

| 변수 | 내용 |
| --- | --- |
| `{song}` | 언어별 곡명. 번역이 비어 있으면 고유 이름 |
| `{artist}` | 그룹명 또는 선택한 캐릭터 이름 |
| `{mod}` | 선택한 MOD 이름과 값 |
| `{costume}` | 의상 이름 및 언어별 의상 접미사 |
| `{ratio}` | `[16:9]`처럼 대괄호를 포함한 화면비. 표시 안 함이면 빈 문자열 |
| `{ratio_raw}` | 대괄호 없는 `16:9` |
| `{type}` | `MOD` 또는 `MV` |

중괄호 자체를 쓰려면 `{{`, `}}`를 사용합니다. 구형 `[{ratio}]` 포맷은 `{ratio}`로 호환 처리하여 대괄호가 중복되지 않습니다. 지원하지 않는 변수는 화면에 오류 이유를 표시합니다.

## 저장·백업·기존 데이터 가져오기

- **자동 저장:** 데이터 편집과 선택을 현재 브라우저의 `localStorage`에 즉시 저장합니다. 재접속 시 마지막 선택을 복원합니다.
- **HTML로 저장:** 데이터·선택 상태·프로그램을 모두 포함하는 휴대용 실행 파일입니다. 기기 이동이나 보관에 권장합니다.
- **데이터 → JSON 내보내기:** 기존 형식의 데이터 JSON을 내려받습니다. JSON 자체에는 프로그램이나 현재 선택 상태가 포함되지 않습니다.
- **데이터 → JSON 불러오기·병합:** 기존 `youtube_data.json`, 전체 데이터 JSON, 단독 곡 사전을 지원합니다. 붙여 넣기도 가능합니다.
- **추가 항목 병합:** 기존 값·설정을 유지하며 새 항목과 없는 필드, 카테고리 관계를 추가합니다. 편집한 기존 값까지 옮기려면 전체 교체 또는 HTML 저장을 사용하세요.
- **전체 데이터 교체:** 확인 후 파일 내용으로 바꿉니다. 형식 검증에 실패하면 현재 데이터는 바뀌지 않습니다.
- **직전 가져오기 되돌리기:** 가져오기 창에서 이전 상태로 되돌립니다. 브라우저 저장을 쓸 수 있으면 새로고침 후에도 복구 기록을 읽습니다. 저장이 제한된 환경에서는 현재 탭이 열려 있는 동안만 유지됩니다.

이전 버전의 `youtube_gen_data_v20` 저장 데이터가 **같은 브라우저에서 접근 가능한 경우** 자동으로 이전하며, 이전 키는 삭제하지 않습니다. Python판에서 사용하던 JSON은 직접 가져오세요. 구형 `costume_categories.Character` 구조도 변환합니다.

### 저장에 문제가 있을 때

`file:` 주소의 저장 방식은 브라우저마다 다르고, 시크릿 모드·쿠키 차단·저장 공간 부족으로 자동 저장이 제한될 수 있습니다. 앱은 이 상황을 알리고 계속 사용할 수 있게 합니다. 닫기 전에 HTML로 저장하세요.

저장된 JSON이 손상되면 기존 문자열을 복구용으로 보관하고 내장 데이터로 실행합니다. 다른 탭이 같은 작업을 변경한 경우에는 덮어쓰지 않고 알립니다. 현재 내용을 HTML로 보관하거나 다른 탭의 내용을 불러올 수 있습니다.

브라우저 데이터 삭제, 브라우저 변경, 파일 이동·이름 변경만으로 편집 내용이 자동 이전되는 것은 아닙니다. **중요한 수정 후에는 HTML 또는 JSON을 내려받아 보관하세요.**

## 이전 버전과의 차이

- Python 서버와 별도 `youtube_data.json`, 중복 UI 코드를 없애고 `index.html`로 통합했습니다.
- Python CLI(`generate`, `selftest`, `build-static`), 디스크 JSON 자동 쓰기, Python 백업 순환 기능은 더 이상 제공하지 않습니다. 브라우저 생성·저장·내보내기로 대체합니다.
- Python이 필요했던 기존 구현은 Git 이력에서 확인할 수 있습니다.
- 복사 실패를 성공으로 표시하던 문제, 의상 없음이 해제되던 문제, 캐릭터별 의상 카테고리가 되돌아가던 문제, 마지막 선택 유실, 빈 번역·화면비 중복 괄호, 편집 시 추가 필드 유실, 잘못된 JSON으로 앱이 멈추는 문제를 수정했습니다.

## 검증 범위

변경 전 Python 생성기를 기준으로 100가지 선택 조합의 세 언어 제목과 전체 설명을 비교해 정확히 일치함을 확인했습니다. Node VM에서 데이터 검증, 병합·교체·되돌리기, 저장·복구, HTML 직렬화와 스크립트 탈출 방지를 확인했습니다. 저장·DOM 관련 단위 검사에는 명시적인 대체 객체를 사용했습니다.

HTML의 ID·레이블·이벤트 연결과 반응형 CSS를 정적으로 검토했습니다. 작업 환경에서 브라우저 실행이 제한되어 **실제 Android 기기, macOS Safari, 브라우저 클립보드·다운로드, 렌더링 화면은 실기기 검증하지 못했습니다.**
